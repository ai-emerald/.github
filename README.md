# .github

Org-wide default community health files for ai-emerald. GitHub uses each file here in any org repo that has no file of its own with the same name.

- [`drafts/pull_request_template.md`](drafts/pull_request_template.md): the proposed default PR description, inactive while under review. Moving it to the repo root makes it the default; a repo overrides it by adding its own `pull_request_template.md`.

This repo must stay public: GitHub only applies org defaults from a public `.github` repo. Don't put anything internal here.
